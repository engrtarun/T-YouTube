The steps

Follow in order. Skipping step 1 or 2 is the #1 reason nothing works.

01

Download microG-RE

Tap the first button below. It lands the official MicroG RE APK straight into your downloads — 107 MB, works on every phone.

Before you start: if Google Play Services is installed on this phone, disable or uninstall it first. microG and Play Services cannot run together, and T YouTube will not start while Play Services is active.
02

Install it

Open the downloaded microg-7.2.1.apk and tap Install. Android will ask you to allow "Install unknown apps" for your browser or file manager — tap Allow and come back. This prompt only appears once.

03

Turn on signature spoofing

Open microG-RE → Settings → Signature spoofing → switch on T YouTube. Then go back.

This is the step almost everyone forgets. Without it the app installs fine but sign-in and video playback silently fail.
04

Install T YouTube

Tap the second button, open T-YouTube-v1.0.0.apk, tap Install. Allow the unknown-app prompt if it appears.

Already have YouTube Pro v59 on the phone? It installs straight on top — no uninstall, and your logins and watch history stay.
05

Open it — and that's it

Launch T YouTube from your app drawer. Sign in, and it plays.

Two things to look for: the launcher icon is the T mark, and the in-app header reads T YouTube — not "YouTube Pro".

Stuck?

Common problems

These cover almost every failure. Try them in order.

“App not installed as package conflicts with an existing package”
A differently-signed copy of the same package is already installed, so Android refuses to replace it.
  • Uninstall the existing YouTube Pro build — ⚠️ this clears its app data.
  • Then install T YouTube. From now on, always update from this build and the error will not come back.
App installs, but it says “MicroG Not Installed”
microG-RE is not running, or signature spoofing is off.
  • Open microG-RE once so it finishes setting up.
  • Then Settings → Signature spoofing → enable T YouTube.
  • If Play Services is still installed, disable it.
Android says “for your security, your phone is not allowed to install unknown apps”
Expected on first install. Tap Settings on that screen, allow Install unknown apps for the app you downloaded from (browser or file manager), then press back and tap Install again.
Videos will not play / everything is blank
microG needs background permission on some phones. In microG-RE settings, exclude it from battery optimisation, and check Settings → Signature spoofing is enabled.
Can I keep the official YouTube too?
Yes — the packages differ, so both can be installed side by side. But since T YouTube needs microG and Play Services cannot coexist with it, in practice you will want only one.
Does it remove in-video ads?
It removes the mod's own startup promo popup. In-stream advertising is served by YouTube's servers and is a separate matter.

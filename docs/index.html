The steps

Two installs, one file to download. Android shows its own confirmation once.

01

Download and install T YouTube

Tap the download button below, open the APK, and tap Install. Android asks you to allow "Install unknown apps" for your browser or file manager — turn it on and come back. This prompt only appears once.

Updating from v1.0.1 or v1.1.0? Install it straight over the old build. Same signature, same package — your logins, settings and downloads stay.
02

Open it and tap Start setup

The first launch shows a short welcome screen. Tap Start setup, then Install on the microG row. Android asks for "Install unknown apps" for T YouTube this time — turn on Allow from this source and go back. The install continues on its own.

The microG APK is already inside T YouTube. Nothing is downloaded, and it works offline. Android still shows its normal installer confirmation — tap Install.
03

Finish the small stuff

Turn on notifications (optional) and battery exemption (recommended on Xiaomi, Samsung and other aggressive battery managers). Then tap Continue → Open T YouTube. Sign in and play a video.

Only T YouTube gets a launcher icon. microG is installed as a separate Android package because Android cannot merge it into another app, but its icon is hidden. Set it up later from Settings → Setup & permissions.

✅ Current update · v1.2.0

One app on your phone: T YouTube installs microG for you

v1.2.0 ends the old two-file routine. The official MicroG-RE APK now ships inside T YouTube, and a short first-run setup installs it. There is no second download, no file manager, and no second launcher icon.

  • One download, one icon. Install T YouTube, tap Start setup, and the bundled microG installs with Android's normal confirmation. microG's launcher icon is hidden; only T YouTube appears in your app drawer.
  • Official microG bytes, unchanged. MicroG-RE 7.3.0 -noicon for arm64-v8a and armeabi-v7a. The app verifies the file and installs it as-is — nothing is modified or re-signed.
  • Setup later, or again. Settings → Setup & permissions sits above About and reopens the checklist in manage mode. Skipped it the first time, or uninstalled microG? Fix it there.
  • No surprise browser. The extension's old checkGmsCore() used to open a microG download page when the service was missing. It is now a no-op, so nothing can pop up behind the setup screen.
  • Issue #2 fixed: the fullscreen watermark. The T YouTube wordmark is now 11.5 sp at 0.55 alpha (was 14 sp at 0.8) — smaller, dimmer, still below the scrubber line and still tied to the controls' visibility. Absent inline, in PiP and in Shorts.
  • Installs straight over v1.1.0 — same package, same version number (21.26.364), same AOSP testkey signature. The About screen shows 21.26.364 (v1.2.0) so you can confirm it.
  • To go back: install v1.1.0 or v1.0.1 over it. No data is lost. You can remove the hidden microG package from Android Settings → Apps at any time.

Optional

Open YouTube links in T YouTube

Purely a convenience. If you would rather not change anything, skip this page — everything in the app already works.

Why this is manual

Android allows one app per website. While the official YouTube app is verified for youtube.com, T YouTube cannot take those links over silently — Google already owns them. You have to hand the links over once, in Android settings.

Setup (about 1 minute)

  • 1. Open the official YouTube app’s link settings.
    Android Settings → Apps → YouTube → Open by default → turn off Open supported links (or remove youtube.com and m.youtube.com from the supported addresses).
  • 2. Give the links to T YouTube.
    Android Settings → Apps → T YouTube → Open by default → Add link → tick youtube.com and m.youtube.com, then Add.
  • 3. Test it. Open a youtube.com link from your browser or a chat app. Android should offer T YouTube (or open it directly).

Shortcut: these two buttons jump straight to each app’s Android settings page when this guide is open on the phone. If your browser blocks them, use the steps above — they are the same screens.

Stuck?

Common problems

These cover almost every failure. Try them in order.

“App not installed as package conflicts with an existing package”
A differently-signed copy of the same package is already installed, so Android refuses to replace it.
  • Uninstall the existing YouTube Pro build — this clears its app data.
  • Then install T YouTube. From now on, always update from this build and the error will not come back.
App installs, but it says “MicroG Not Installed”
microG is missing, turned off, or was uninstalled.
  • Open T YouTube → Settings → Setup & permissions.
  • Tap Install on the microG row. The APK is bundled — nothing is downloaded.
  • If the row says the app is turned off, tap Turn on and enable it in Android settings.
  • If Play Services causes sign-in trouble, disabling it is a troubleshooting step, not a requirement.
Android says “for your security, your phone is not allowed to install unknown apps”
Expected on first install. Tap Settings on that screen and allow Install unknown apps for the app you downloaded from (browser or file manager). You will see the same prompt once more during setup, this time for T YouTube itself, because it installs the bundled microG. Turn on Allow from this source, go back, and setup continues automatically.
Videos will not play / everything is blank
microG needs to stay awake on some phones. Open Settings → Setup & permissions, make sure the microG row is green, and tap Allow on the battery row. If sign-in still fails, open the existing MicroG settings row and check that microG is enabled.
Download still fails / says “file not created”
  1. Open Settings → Downloads → download folder and choose Internal storage (not the SD card), then retry the same video.
  2. If it works on internal storage, the old folder/SD card was the problem.
  3. If it still fails, send the video title or link and the exact error text.
Can I keep the official YouTube too?
Yes — the packages differ, so both can be installed side by side. Current MicroG-RE coexists with Google Play Services. If sign-in misbehaves with both active, disable Play Services and retry; that is troubleshooting, not a required step.
Does it remove in-video ads?
It removes the mod's own startup promo popup. In-stream advertising is served by YouTube's servers and is a separate matter.
